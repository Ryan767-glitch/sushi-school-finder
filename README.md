# SUSHI SCHOOL FINDER

日本全国の実在する寿司スクールを比較・検索するサイトです。

## できること

- 条件検索（通学／オンライン、学費、期間、英語対応、就職・開業支援）
- 最大5校の比較
- お気に入り（端末内のみ保存）
- 編集部ランキング
- 資料請求フォーム（入力検証・ハニーポット・レート制限）
- 各校の Google マップ連携

## データの扱い

学費・住所は各校公式サイトなどの公開情報（2026年8月調査）に基づく目安です。総合評価は Google マップ API のライブ取得ではなく、公開情報を整理した参考値です。最新の地図評価は各校ページの「Googleマップで見る」から確認してください。

確認できなかった地域の学校は、架空の店舗を作らず未掲載としています。

## 開発

```bash
npm install
npm run dev
```

## 環境変数（任意）

- `NEXT_PUBLIC_SITE_URL` 本番URL
- `INQUIRY_WEBHOOK_URL` 資料請求の転送先（HTTPSのみ）

## デプロイ

Vercel に接続して本番公開します。ドメインはあとから Vercel の Domains に追加できます。
